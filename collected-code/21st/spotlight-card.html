Spotlight Card

把鼠标移到卡片上，一束光会跟着你的指尖走，照亮卡片的每个角落。离开后光斑缓缓淡出。

✦

跟随指尖的光斑

卡片实时读取鼠标坐标，用径向渐变在指尖位置投下一圈柔光，内容仿佛被手电筒照亮。

mousemove 追踪
◈

每张卡片独立响应

网格里的卡片互不干扰：你指到哪一张，哪一张亮起，其余保持安静的深色。

独立作用域
❖

离开即淡出

鼠标移开后光斑不做生硬消失，而是用 0.35 秒的过渡缓缓隐去，像灯被轻轻调暗。

opacity 过渡
✧

边缘也被点亮

除了内部光斑，卡片描边同样跟随指尖发光——光走到哪里，边框就亮到哪里。

边框高光

纯 CSS 变量 + radial-gradient 实现 · 零依赖
