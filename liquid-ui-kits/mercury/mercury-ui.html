使用说明

整套组件只用 2 套渐变 + 1 个球体公式拼出来：

① --chrome 流光铬面 = 所有按钮与徽标的高光
② --sphere 水银球 = 开关旋钮 / 头像 / 顶饰
③ blur+contrast = 黏性聚合加载动画
④ 按下时 border-radius 液化 = 表面张力

◍

水银弹窗

毛玻璃底 + 水银球顶饰。点遮罩或取消可关闭。
