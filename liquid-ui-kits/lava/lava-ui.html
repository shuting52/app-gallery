使用说明

整套组件只用 3 个主色 + 1 条流动渐变 + 2 种玻璃拟态拼出来：

① .btn-lava + lavaflow = 会流动的岩浆
② backdrop-filter: blur() = 玻璃拟态卡片与胶囊
③ clip-path: var(--drop) = 随处可用的熔滴
④ .lavabg = 背景的岩浆斑块与上升火星
