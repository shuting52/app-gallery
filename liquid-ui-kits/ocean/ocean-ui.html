使用说明

整套组件只用 3 个套路拼出来：

① .glass = 毛玻璃 + 顶部折射高光
② .btn-blob = morph 液滴按钮
③ .wavebar = 双旋浪花进度条
④ .toast .bub = 上浮气泡

深海弹窗
