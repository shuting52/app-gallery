设计语言小结

整套组件围绕「粘稠流淌」展开：

① .btn-honey 高光折射 + 沉底阴影 = 一勺立体蜜
② .btn-wave 双层波浪 = 会灌满的按钮
③ clip-path: var(--hex) = 蜂巢六边形头像 / 按钮 / 图标
④ 蜜滴造型 = 评分、加载、滑杆拇指的共同母题
