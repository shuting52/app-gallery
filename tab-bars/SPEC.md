# 底部 Tab 栏 22 款 · 构建规范

## 目标
22 个单文件 HTML，每款一款底部 Tab 栏设计，机制互不重复（禁换皮：只改颜色/圆角不算新款）。
全部完成后收进代码全集页（预览图 + 完整代码一键复制）与画廊总库。

## 文件
- 目录：`~/workspace/tab-bars/`
- 命名：`d01.html` … `d22.html`（d = dock/tab）
- `manifest.json`：`[{"file":"d01.html","title":"液态玻璃"}, …]`，title 为中文名（下方概念表）

## 每款硬性要求
- 单文件、纯手写 CSS/JS，无框架、无 CDN、无外部引用（`http` 出现 0 次），零 `alert()`。
- 430×900 视口：顶部一个手机内容区（简单聊天/信息流 mock，原创中文内容，至少 6 行，内容区要有色彩，
  以便模糊/透明类底栏有效果），底部是本款 Tab 栏。
- Tab 栏：4 个 tab（首页/发现/消息/我，或贴合风格改名），点击切换 active 态，**切换必须有本款的标志性动效**。
- 每款附 `?tab=N`（0-3）深链直达，用于截图。
- 概念互不重复：动效机制、视觉语言至少其一是新的。

## 22 款概念（每款一句话机制，不许偷换）
| 文件 | 中文名 | 机制 |
|---|---|---|
| d01 | 液态玻璃 | backdrop-filter 实时模糊身后内容 + 顶部反光 + 底部折射光晕 |
| d02 | 果冻弹性 | 点击时图标果冻形变（scale 挤压回弹），CSS keyframes |
| d03 | 墨水滴 | 墨滴形指示器带飞溅粒子滑到 active tab |
| d04 | 霓虹灯管 | 深色底栏，active 图标霓虹辉光 + 顶部灯管线条点亮 |
| d05 | 黏土按压 | active tab 内凹柔阴影（pressed-in），图标浮起 |
| d06 | 3D翻牌 | tab 像卡片一样 3D 翻转切换正反面（图标→文字） |
| d07 | 液态滑块 | SVG goo 滤镜，果冻 blob 在 tab 间滑动，active 被 blob 托起 |
| d08 | 像素风 | 像素描边、指示器按像素格跳跃（steps 动画） |
| d09 | 描边点亮 | SVG 图标 stroke-dashoffset 描绘动画点亮 active |
| d10 | 波浪顶边 | 底栏顶边是 SVG 波浪，持续流动，active 处波峰隆起 |
| d11 | 弹簧凸起 | active 图标用弹簧曲线弹出底栏上方，带文字标签 |
| d12 | 悬浮胶囊 | iOS 风悬浮胶囊 dock，active 小圆点 + 图标上浮 |
| d13 | 分段胶囊 | 分段控制器，白色滑块胶囊在段间滑动 |
| d14 | 纸质标签 | 和纸质感 tab，像贴纸一样微倾，active 有胶带 |
| d15 | 发光轨道 | 底栏有一条横向轨道，发光点滑到 active 下方 |
| d16 | 渐变流光 | 底栏边框是流动渐变光带（background-position 动画） |
| d17 | 极简细线 | 纯文字 tab，顶部一根 2px 细线指示器滑动 |
| d18 | 3D透视 | 点击时整个底栏 3D 倾斜，图标依次弹起（stagger） |
| d19 | 气泡上升 | 点击 tab 冒出上升气泡粒子，active 图标呼吸 |
| d20 | 赛博HUD | 斜切边框 + 扫描线 + HUD 角标，active 数据闪烁 |
| d21 | 花瓣绽放 | 激活时图标周围绽放一圈小花瓣，随即收拢 |
| d22 | 标签抽屉 | 点击 tab 从下方抽出一张小标签卡片显示名称 |

## 自验（每路 agent 必须做）
- `node --check` 提取的内联 JS（或至少保证无语法错）。
- headless chrome 截图：`--window-size=430,900 --virtual-time-budget=5000 --screenshot`，
  默认态 + `?tab=2` 各一张，**亲自看图**：无白屏、无错位、动效标志可见。
  已知假象：virtual-time 下 transition/animation 可能冻结在起始态，以 DOM 类名为准，
  真机正常；必要时做去 transition 副本验证。
- `manifest.json` JSON 合法，22 条，文件逐一存在。
- 回报：文件绝对路径 + 标题 + 自验结论 + 修过的真 bug。
