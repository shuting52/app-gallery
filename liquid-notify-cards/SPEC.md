# 液态玻璃通知卡 100 款 · 构建规范

照用户给的「液态玻璃通知卡片」代码骨架（见本目录 `template.html`），做 100 款**液态玻璃**通知卡片，每款独立单文件。

## 固定骨架（照抄 template.html）

- 整页 `body`：液态流体背景（多层 radial-gradient + linear-gradient，可换色系）。
- `main`：`.heading`（eyebrow + h1 + hint）+ 2–3 张 `.card` 通知卡。
- 每张 `.card`：磨砂玻璃（backdrop-filter blur+saturate + 顶部内高光）+ `::before` 流动高光 + `::after` 右上弧形亮斑（位置/角度可变）+ 圆角 28px。
- 卡内结构：`.top`（类型 pill + 头像组）+ `.row`（大头像/图标 + 标题行 + 预览 + 未读/时间）。
- 可加：操作按钮（回复/查看/忽略）、进度条、图片缩略图、语音条、小红点。

## 100 款必须各不相同（10 组 × 10）

- 背景色系：彩虹/深海/霓虹/果冻/墨晕/晨雾/熔岩/薄荷/蜜桃/水银……
- 玻璃变化：透明度/模糊度/边框光颜色/高光流动方向/弧斑位置大小。
- 通知类型：私聊/群聊/系统/订单物流/日程/音乐/运动/支付/天气/社交/邮件/验证码……
- 布局变化：头像左/右/上、单行/双行、带按钮/不带、横滑操作……
- 文案全部原创（人名/群名/消息内容不许重复雷同）。

## 交付

- 目录 `~/workspace/liquid-notify-cards/`，文件 `n01.html`–`n100.html`（每人负责的编号段见任务）。
- 每人写 `_titles_nc_<a|b|c|d|e|f|g|h|i|j>.json`：`[{"file":"n01.html","title":"标题"}]`，标题 2–6 字，不许与画廊现有标题重名（完工后我统一查重改名）。
- 每款 headless chrome 截图（整页，宽 430 左右）亲自看过、无空白错位再交。
- 纯手写 CSS，零外部资源；动画用负延迟/both 保证截图饱满。
