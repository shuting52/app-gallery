# 新组件案例 · 构建规范（100 组，5 大类 × 20）

目标：100 组**新鲜、互不重复**的单文件 HTML 组件演示，纯手写 CSS/JS，无框架无 CDN，中文界面，手机端正常。
截图工具：`CH=/home/hatch/.cache/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`，
用法：`$CH --no-sandbox --disable-gpu --window-size=430,900 --virtual-time-budget=5000 --screenshot=<png> "file://<html>"`。

## 通用要求（每组必须）
1. 单文件，舞台居中（约 360px 宽），顶部小标题说明组件名，整体有设计感（深色/主题背景）。
2. 20 组之间必须是**视觉与机制都不同**的概念，禁止换皮（只改颜色/大小算不合格）。
3. 禁用 `alert()`；无外部资源；JS 经 `node --check` 或浏览器无报错。
4. 每组写完必须 headless 截图自验（动画类截动效中途态），白屏/报错修好再交。
5. 完工后在所属目录写 `manifest.json`：`[{"file":"l01.html","title":"呼吸光点"}, …]`（title 为简洁中文名）。
