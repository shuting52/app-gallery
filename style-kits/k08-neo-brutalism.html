风格介绍

04

用法代码

两行 CSS 就是全部秘诀，点右下角复制。

/* 新粗野主义核心 token */
.brutal {
  border: 3px solid #111;
  box-shadow: 4px 4px 0 #111;
  background: #FFD02F;
  font-weight: 900;
}
.brutal:active {
  transform: translate(3px,3px);
  box-shadow: 1px 1px 0 #111;
}
